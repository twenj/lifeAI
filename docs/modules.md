# 「我的生活」模块

模块入口：聊天页右上角九宫格 → **我的生活**。

## 分类

| 分类 | 模块 |
|------|------|
| 健康 | 体重记录、饮食记录、食物库 |
| 日常 | 记事本、日程、日记 |
| 消费 | 记账、待购买 |
| 设置 | 数据共享 |

## 模块说明

### 体重记录

- 一天可记录多次；可选日期与时间
- 列表显示日期 + 时间
- 聊天含「体重」+ 数字时可自动入库

### 饮食记录

- 首页只展示**今日**总量与今日明细
- **历史记录**：按日期列表 → 进入某天看明细与总量
- 明细可编辑重量、日期；关联食物库时改重量会重算热量/蛋白质
- 饮食不分餐次，按自然日汇总
- 聊天含「饮食」时可自动写入饮食记录

### 食物库

- 聊天识图入库：完整营养字段（热量/蛋白/脂肪/碳水/糖/纤维/钠等）
- 手动新增：精简版（名称 / 份量 / 热量）；之后点「编辑」可补全营养
- 编辑：与识图一致的完整字段
- 支持搜索；一键加入今日饮食（弹框输入重量）
- **同名不重复添加**（同一用户）
- 聊天入库条件：带图 + 文案含「食物」

### 记事本

- 笔记 CRUD；聊天含「记事」时可自动写入

### 日程

- 日程 CRUD；可含提醒字段；聊天含「日程」时可自动写入

### 日记

- **每日自动生成**（后端定时任务），不走聊天关键词分类
- 可在模块内查看/编辑

### 记账

- 以**自然月**为周期
- 首页只展示**当月**汇总与流水，可新增/删除
- **历史记录**：按月份列表 → 进入某月看明细与结余
- 聊天含「收入」或「支出」且有金额时可自动写入

### 待购买

- **短期**：可勾选已购买（沉底）、清空已购
- **长期**：常备提醒，无勾选；支持按住 ≡ **拖动排序**（持久化）
- 字段仅名称；短期 ↔ 长期可互转
- 聊天含「购买」时可自动写入

### 数据共享

- 生成本机共享码 / 二维码
- 另一台设备输入共享码后切换到同一用户数据
- 加入后本机原匿名数据不会自动合并
- H5 网页端不支持扫码，需手动输入共享码
