# Decisions

- 2026-07-11: 前端 uni-app（Vue3+Vite）；模型走 OpenRouter `openai/gpt-4o-mini`，`supportsVision=true`
- 2026-07-11: OpenRouter `X-Title` / `HTTP-Referer` 必须 ASCII
- 2026-07-11: 历史持久化剥离图片 base64，避免 storage 过大
- 2026-07-12: 后端采用同级目录 Node.js + Fastify + TypeScript；MySQL + Prisma
- 2026-07-12: 前端聊天/会话/模块统一走独立 Node API，不再依赖微信云函数
- 2026-07-12: 初期匿名 JWT；可用共享码跨设备切到同一用户（不自动合并原数据）
- 2026-07-12: 饮食记录不分餐次，只按自然日汇总总摄入量
- 2026-07-12: 「功能模块」改名「我的生活」；分组：健康 / 日常 / 消费 / 设置
- 2026-07-12: 待购买放在「消费」；短期可勾选已购，长期仅提醒；字段仅名称
- 2026-07-12: 聊天自动入库必须命中关键词门禁（体重/饮食/记事/日程/购买/收入|支出；食物库=图+「食物」）
- 2026-07-12: 日记仅每日定时生成，不走聊天分类
- 2026-07-12: 体重一天可多条，表单可选日期+时间；列表显示日期时间
- 2026-07-12: 饮食首页只显示今日；历史走独立列表/日详情页；可 PATCH 日期与重量
- 2026-07-12: 食物库同名（同用户）不重复添加；手动表单主要填名称/份量/热量
- 2026-07-12: H5 数据共享不提供扫码，仅手动输入共享码
- 2026-07-12: 聊天/识图/代理超时统一约 180s；分类约 90s
- 2026-07-12: 用户文档放在 `lifeAI/docs/`；AI 协作记忆放在 `lifeAI/.ai/`（勿用家目录 `~/.ai`）
- 2026-07-12: Project Memory 用项目级 .cursor/mcp.json 配置；lifeAI 的 PROJECT_MEMORY_ROOT 使用绝对路径 /Users/tangwenjing/WeChatProjects/lifeAI，不以未可靠展开的 ${workspaceFolder} 或 ~/ 相对路径为准。
- 2026-07-12: 食物库：聊天识图与编辑使用完整营养字段；手动新增保持精简（名称/份量/热量）。
- 2026-07-12: 聊天关键词入库后，模型需简短确认（如购买→待购买），避免当成闲聊科普；规则命中时接口返回 applied 供前端 toast。
- 2026-07-12: 待购买长期清单支持拖动排序：ShoppingItem.sortOrder + PUT /v1/shopping-items/reorder；短期仍按已购/更新时间。
- 2026-07-12: 记账优先于购买：含「收入/支出」不进待购买；记账必须 amount>0 才 applied；纯金额短句会拼上同会话最近一条支出/收入上下文。
- 2026-07-12: 聊天多关键词时按出现位置：越靠前权重越高，只归入最先出现的模块（primaryKeywordCategory）。
- 2026-07-12: 记账以自然月为周期：首页仅当月；历史记录列出往月，可进入月度明细。
- 2026-07-12: 记账自动入库关键词使用“收入/支出”，不使用“记账”作为触发词。
